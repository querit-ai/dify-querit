# Privacy Policy

This Privacy Policy explains how the Querit plugin for Dify handles data.

## Data we process

When you use this plugin, the following data is sent to the Querit API
(`https://api.querit.ai`) over HTTPS to fulfill your request:

- Search queries you provide, and for the Contents tool the URLs you supply.
- Search/crawl options you set (result count, filters, time range, language).
- Monitor configuration (name, schedule, search query) when creating or running a monitor.
- Your Querit API key, sent as a Bearer credential for authentication.

## How the data is used

Only to perform the requested web search, page-content retrieval, or scheduled
monitoring, and to return results to your Dify application.

## Data retention

The plugin does not store or log your queries, URLs, credentials, or results; it
forwards requests to the Querit API and returns the responses. Data processing by
the Querit service is governed by Querit's own policies.

## Third-party service

This plugin relies on the Querit service (querit.ai). See Querit's privacy policy
for how Querit processes and retains data.
